PE Studio 安装与使用说明

把一句随手输入的想法，优化成三份提示词，再由 Jev 比较。支持普通、生图、视频和产品四个方向。应用输出提示词，不直接生成图片或视频。

1. 选择适合你的 MacBook 的安装包

本版适配 MacBook，基础功能需要 macOS 13 或以上版本，无需安装 Node.js。原生 Liquid Glass 需要 macOS 26 或以上；旧系统使用兼容材质。
点屏幕左上角苹果菜单 → 关于本机：
• 显示 Apple M 系列芯片：选择文件名带 arm64 的包。
• 显示 Intel 处理器：选择文件名带 x64 的包。
两个包任选适合的一份，不需要都安装；不适用于 Windows。

2. 安装与第一次打开

在 Mac 微信上下载 ZIP，双击解压，将 PE Studio.app 拖到“应用程序”（Applications）文件夹，再从那里打开。Finder 可能只显示“PE Studio”，不显示 .app 后缀。

这是试用版，采用 ad-hoc 临时签名，尚未使用 Developer ID 签名并完成 Apple 公证。其他 Mac 首次打开时可能被系统拦截，不能保证双击即可运行。

若提示无法验证开发者或 Apple 无法检查是否含恶意软件，请先向发送者确认文件来源和完整性。确认可信且未被篡改、并决定继续时，可按 Apple 官方流程操作：
① 先尝试打开一次应用。
② 打开“系统设置”→“隐私与安全性”，向下找到 PE Studio 的拦截提示，点“仍要打开”。
③ 阅读再次出现的提示，确认后点“打开”；按系统要求验证身份。

如果没有此选项，或提示“已损坏”“将损坏你的电脑”，请停止并联系发送者；公司管理的 Mac 可能需要 IT 协助。
Apple 官方说明：https://support.apple.com/zh-cn/102445

3. 先体验，再配置

右键菜单栏图标 → “任务”，在后台点击“查看演示”，无需 Key。示例提示词和分数均为手工演示，不代表真实模型调用结果。

要生成自己的提示词，需要联网，并使用接收者自己的 AiHubMix API Key 和独立的 Typesafe / Jev API Key。模型服务按各自账号规则计费，应用包不附带他人的 Key 或额度。

4. 配置三个写作模型与 Jev

右键菜单栏图标 → “设置…”，或按 Command + , 打开独立后台窗口：
① 点击“一键将三组切换为 AiHubMix”。
② 三个槽位均使用“推理时代 / AiHubMix”协议，Base URL 为 https://aihubmix.com/v1。
③ 三个槽位可分别填写以下 Model ID（保留大小写）：
   gpt-6-astra
   claude-opus-5-5
   gemini-4-argon
   可按账号权限换用 AiHubMix 模型目录中的其他精确 ID。
④ 每个槽位填写自己的 AiHubMix Key；同一个有效 Key 可填入三组，不必创建三个账号。
⑤ 在下方 Jev 评审中填写自己的 Typesafe / Jev Key，保留默认模型和 Base URL：https://api.typesafe.ai/v1。
⑥ 点击“保存设置”。

一键切换会保留原有模型名与 Key，请逐组核对。AiHubMix Key 不应搭配 OpenAI、Anthropic 或 Google 官方地址；Jev 使用自己的 Key。

主线路不通时，可在设置中手动选择备用线路 https://api.inferera.com/v1，保留相同的 AiHubMix Model ID 和 Key。
模型目录：https://aihubmix.com
AiHubMix 接入说明：https://docs.aihubmix.com/en/quick-start
Jev API 说明：https://docs.typesafe.ai/api

5. 日常使用

• 应用启动后，按 Control + Q（⌃Q）唤起；也可点击屏幕顶部菜单栏的 PE Studio 图标。
• 在小窗选择方向、输入想法，点击“优化提示词”，或按 Command + Enter。
• 目标模型、背景、约束和语言可在后台“当前任务”中补充；目标模型可自由填写。应用补充不改变小窗的正文和方向。
• 点击 GPT、Claude、Gemini 等品牌文字，在旁边展开对应的结果泡泡；三份结果都会保留。泡泡里可比较真实分数、阅读和复制全文。改写说明、假设、评分维度、收藏和 Markdown 导出放在后台“历史与收藏”。评分是比较指标，不是成功率。
• 输入小窗和结果泡泡作为一组；组内切换不会收起。点击整组外部、切换到其他应用、按 Esc，或再次按 Control + Q，都会收起整组。正在运行的任务继续，结果完成后不会抢焦点。
• 拖动小窗或结果泡泡的留白即可移动整组，位置会保留。结果空间不足时改为切换展示，不丢失内容。小窗以泡泡展开，外观跟随深浅色及系统无障碍偏好。后台窗口失焦时保留未保存的草稿。
• 某一路失败时可在结果泡泡查看连接详情并单独重试，其他结果保留。Jev 未完成时显示未评分，不补造分数。
• 彻底退出：右键菜单栏图标，选择“退出 PE Studio”。退出后快捷键不再生效。
• 快捷键冲突时，可从菜单栏打开设置并更换。重启电脑后可从“应用程序”再次启动。

保存后的 Key 由 macOS 钥匙串保护的密钥加密存储在本机；历史也保存在本机。请勿把自己的 Key 或应用用户数据文件夹转发给别人。
